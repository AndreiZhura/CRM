# Lumen Alpha CRM — управление заказами для малого бизнеса

**Lumen Alpha** — это простая, но мощная CRM-система, созданная специально для малого бизнеса в сфере услуг (HVAC, клининг, ремонт, доставка). Она помогает вести учёт заказов, клиентов, монтажников, финансов и гарантийных случаев. Всё, что нужно для контроля бизнеса в одном месте.


---
## Возможности

- **Заказы** — создание, редактирование, просмотр. Поддержка нескольких позиций и нескольких монтажников в одном заказе.
- **Клиенты** — база клиентов с контактными данными и историей заказов.
- **Монтажники** — учёт специалистов, их специализации, рейтинга, долгов и статистики.
- **Финансы** — автоматический расчёт прибыли, себестоимости, выплат монтажникам. Сводка по периодам, графики.
- **Гарантия** — учёт гарантийных случаев с распределением ответственности (производитель / монтажник / компания).
- **Карта** — визуализация заказов на карте с цветовой индикацией статуса.
- **Напоминания** — автоматические уведомления о «зависших» заказах.
- **Бэкапы** — ежедневное резервное копирование базы данных и отчётов на Яндекс.Диск.
- **Тёмная тема** — для комфортной работы в любое время суток.

---

## Технологический стек

- **Backend:** Python 3.12 + FastAPI (асинхронный)
- **База данных:** PostgreSQL 15 (в Docker)
- **ORM:** SQLAlchemy 2.0 + asyncpg
- **Планировщик:** APScheduler + pgAgent
- **Фронтенд:** React 19 + React Router v7
- **Стили:** CSS-переменные, адаптивная вёрстка (mobile-first)
- **Инфраструктура:** Docker, nginx, Let's Encrypt
