# CRM для Олега (HVAC)

Проект представляет собой полнофункциональную CRM-систему для управления заказами в сфере HVAC (кондиционирование, монтаж, обслуживание). Система включает в себя управление клиентами, монтажниками, заказами, финансами, геокодинг, карту, прогноз погоды и ML-модуль для прогнозирования спроса.

## Основные возможности

- 📝 Создание и редактирование заказов с выбором клиента и монтажника.
- 👥 Управление клиентами и монтажниками (мягкое удаление, резервный телефон).
- 💰 Финансовый учёт: автоматический расчёт прибыли, выплаты монтажникам, сводка и график.
- 🗺️ Отображение заказов на карте с цветными маркерами (Яндекс.Карты).
- ⚡ Автодополнение адреса при вводе (геокодер Яндекса).
- 🌙 Тёмная тема с переключателем.
- 📱 Полностью адаптивный интерфейс (Mobile First).
- 📧 Ежедневные напоминания о «зависших» заказах по email.
- ☁️ Автоматический сбор погоды (Open-Meteo).
- 🤖 ML-модуль для прогнозирования спроса (отдельный контейнер).
- 💾 Автоматические бэкапы на Яндекс.Диск.

## Технологический стек

- **Backend:** Python 3.12, FastAPI, SQLAlchemy 2.0, asyncpg, APScheduler
- **Database:** PostgreSQL 15 (Docker)
- **Frontend:** React 19, React Router v7, recharts, react-select, CSS-переменные
- **Инфраструктура:** Docker Compose, nginx (планируется), Яндекс.Диск для бэкапов
