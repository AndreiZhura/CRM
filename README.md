# ❄️ Lumen Alpha CRM — Управление заказами для малого бизнеса

**Lumen Alpha** — это простая, но мощная CRM-система, созданная специально для малого бизнеса в сфере услуг (HVAC, клининг, ремонт, доставка). Она помогает вести учёт заказов, клиентов, монтажников, финансов и гарантийных случаев. Всё, что нужно для контроля бизнеса в одном месте.

Проект полностью функционален, развёрнут на сервере и готов к коммерческому использованию (on-premise).

---

## ✨ Возможности

- **📦 Заказы** — создание, редактирование, просмотр. Поддержка нескольких позиций (товары/услуги) и нескольких монтажников в одном заказе.
- **👥 Клиенты** — база клиентов с контактными данными (основной и резервный телефон), адресом, историей заказов.
- **👨‍🔧 Монтажники** — подробный учёт специалистов: ФИО, кличка, телефоны, специализация, рейтинг, базовая ставка, статус активности (активен/уволен/в отпуске/на больничном), отметка о долге с суммой. В списке мастеров статусы отображаются цветными бейджами, а отсутствие долга — зелёной галочкой ✓.
- **💰 Финансы** — автоматический расчёт прибыли, себестоимости, выплат монтажникам, непредвиденных расходов. Сводка по периодам, график прибыли по месяцам, фильтр «Только выполненные заказы».
- **🛡️ Гарантия** — учёт гарантийных случаев с распределением ответственности (производитель / монтажник / компания). В журнале заказов добавлена колонка «Гарантия» с индикацией проблем (⚠️ — есть открытые случаи, ✓ — проблем нет) и фильтр «Только с проблемами по гарантии».
- **🗺️ Карта** — визуализация заказов на карте с цветовой индикацией статуса (активные заказы). По клику на метку — быстрый переход к заказу.
- **⏰ Напоминания** — автоматические уведомления о «зависших» заказах (ежедневно в 9:00).
- **💾 Бэкапы** — ежедневное резервное копирование базы данных (pg_dump) и генерация Excel-отчёта со сводкой по заказам. Файлы сохраняются локально и загружаются на Яндекс.Диск.
- **🌙 Тёмная тема** — переключение светлой/тёмной темы для комфортной работы в любое время суток.
- **📱 Адаптивный дизайн** — интерфейс оптимизирован для работы на мобильных устройствах (mobile-first).

## 🛠️ Технологический стек

| Компонент                     | Технологии                                                                |
| -------------------------------------- | ----------------------------------------------------------------------------------- |
| **Backend**                      | Python 3.12, FastAPI (асинхронный), SQLAlchemy 2.0, asyncpg, APScheduler |
| **Database**                     | PostgreSQL 15 (в Docker), pgAgent                                                  |
| **Frontend**                     | React 19, React Router v7, recharts, react-select, @pbe/react-yandex-maps           |
| **ML-сервис**              | TensorFlow/Keras, scikit-learn, joblib (отдельный контейнер)      |
| **Инфраструктура** | Docker, Docker Compose, nginx (reverse proxy), Let's Encrypt (SSL)                  |
| **Бэкапы**                 | yadisk 3.4, xlsxwriter, postgresql-client                                           |
