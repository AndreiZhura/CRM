# Lumen Alpha — CRM для управления заказами в сфере HVAC

[![Python](https://img.shields.io/badge/python-3.12-blue.svg)](https://www.python.org/)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.104.1-green.svg)](https://fastapi.tiangolo.com/)
[![React](https://img.shields.io/badge/react-19-blue.svg)](https://reactjs.org/)
[![PostgreSQL](https://img.shields.io/badge/PostgreSQL-15-blue.svg)](https://www.postgresql.org/)
[![Docker](https://img.shields.io/badge/docker-compose-blue.svg)](https://www.docker.com/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

**Lumen Alpha** — это полнофункциональная CRM-система, разработанная для малого бизнеса в сфере HVAC (установка и обслуживание кондиционеров). Проект создан с учётом реальных потребностей владельца бизнеса (Олега) и включает управление заказами, клиентами, монтажниками, финансами, а также прогнозирование спроса на основе погоды и ML.

## 🚀 Основные возможности

- **Управление заказами**Создание, редактирование и отслеживание заказов. Поддержка нескольких позиций (товаров/услуг) и нескольких монтажников в одном заказе с разными ролями и оплатой.
- **Клиенты и монтажники**Полный CRUD для клиентов и монтажников. Мягкое удаление, резервные телефоны, специализация, рейтинг, статус должника. В профиле монтажника отображаются все его заказы (активные и выполненные).
- **Финансовый учёт**Автоматический расчёт прибыли по каждому заказу, учёт непредвиденных расходов, выплат монтажникам, гарантийных затрат. Финансовая сводка с графиком прибыли по месяцам и фильтром «Только выполненные заказы».
- **Гарантийные случаи**Регистрация гарантийных обращений с распределением ответственности (производитель, монтажник, Олег) и отслеживанием статуса.
- **Геокодинг и карта**Автодополнение адресов при вводе (Яндекс.Карты). Отображение активных заказов на карте с цветовой легендой (статусы: Новый, Ждёт установщика, В работе). Заказы со статусами «Выполнен» и «Отменен» на карте не показываются.
- **Погода и прогнозирование**Ежедневный сбор данных о погоде (Open-Meteo). ML-модуль (TensorFlow) для прогнозирования спроса на основе истории заказов и погодных условий (в разработке).
- **Автоматические бэкапы**Ежедневные дампы базы данных и Excel-отчёты с загрузкой на Яндекс.Диск.
- **Тёмная тема**Переключение между светлой и тёмной темой с сохранением в localStorage.
- **Адаптивный дизайн**
  Полностью адаптирован для мобильных устройств (Mobile First).

## 🛠 Технологический стек

### Backend

- Python 3.12
- FastAPI 0.104.1 (асинхронный)
- SQLAlchemy 2.0.23 + asyncpg
- PostgreSQL 15 (в Docker)
- APScheduler 3.10.4 (планировщик задач)
- JWT-авторизация (python-jose, bcrypt)
- Open-Meteo API (погода)
- Яндекс.Диск API (бэкапы)

### Frontend

- React 19 (Create React App)
- React Router v7
- React Select 5.10.2
- Recharts 3.7.0 (графики)
- @pbe/react-yandex-maps 1.2.5
- CSS-модули + CSS-переменные (тёмная тема)

### Инфраструктура

- Docker, Docker Compose
- Nginx (reverse proxy)
- Let's Encrypt (SSL)
- Защита от случайного удаления томов (`install-protection.sh`)

## 📦 Установка и запуск

### Требования

- Docker и Docker Compose
- Node.js 18+ (для разработки фронтенда)
- Python 3.12+ (для разработки бэкенда, опционально)

### Быстрый старт (локальная разработка)

1. **Клонируйте репозиторий**

   ```bash
   git clone https://github.com/AndreiZhura/CRM.git
   cd CRM
   ```
2. **Настройте переменные окружения**
   Скопируйте `.env.example` в `.env` и заполните необходимые ключи (Яндекс.Карты, Яндекс.Диск, почта и т.д.).

   ```bash
   cp .env.example .env
   ```
3. **Запустите базу данных (Docker)**

   ```bash
   docker-compose up -d db
   ```
4. **Запустите бэкенд** (локально, вне Docker)

   ```bash
   cd backend
   python -m venv venv
   source venv/bin/activate  # или venv\Scripts\activate на Windows
   pip install -r ../requirements.txt
   uvicorn src.main:app --reload
   ```
5. **Запустите фронтенд**

   ```bash
   cd frontend
   npm install
   npm start
   ```
6. **Откройте приложение**
   Фронтенд будет доступен по адресу `http://localhost:3000`, бэкенд — `http://localhost:8000`.

### Запуск в production (Docker Compose)

```bash
docker-compose up -d --build
```

После этого будут запущены все сервисы: база данных, бэкенд, ML-контейнер. Фронтенд собирается в образ и раздаётся через nginx.
