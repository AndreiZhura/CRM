# Быстрый старт для Олега

Добро пожаловать в CRM для управления заказами! Здесь вы найдёте основные шаги, чтобы начать работу.

## Вход в систему

1. Откройте браузер и перейдите по адресу: `http://ваш-сервер/` (или локально `http://localhost:3000`).
2. Введите логин и пароль, которые вы получили при регистрации.
3. Нажмите «Войти».

## Главное меню

После входа вы увидите шапку с ссылками:

- **Новый заказ** — создание заказа.
- **Журнал** — список всех заказов.
- **Мастера** — список монтажников.
- **Добавить мастера** — добавление нового монтажника.
- **Финансы** — сводка по прибыли.
- **Карта** — отображение заказов на карте.
- **🌙/☀️** — переключение тёмной/светлой темы.

## Создание заказа

1. Нажмите «Новый заказ».
2. Заполните карточку клиента: можно выбрать существующего или создать нового.
3. Укажите даты и время обслуживания, доставки.
4. Назначьте монтажника (из списка) и выберите цвет маркера для карты.
5. Введите финансовые данные (закупка, продажа, оплата монтажнику, ваша комиссия). Прибыль рассчитается автоматически.
6. Нажмите «Создать карточку заказа».

## Просмотр и редактирование заказов

- В «Журнале» вы увидите таблицу заказов. Кликните по строке, чтобы открыть детали и отредактировать.
- Можно фильтровать заказы по клиенту, адресу и статусу.

## Работа с монтажниками

- В разделе «Мастера» отображается список всех монтажников. Можно искать по имени или специализации, фильтровать только должников.
- Кликните по имени, чтобы открыть карточку монтажника и отредактировать данные (ФИО, телефон, резервный телефон, специализацию, ставку, заметки, пометить как должника).

## Финансовая сводка

- Перейдите в «Финансы». Здесь вы увидите общую прибыль, сумму выплат монтажникам, количество заказов и среднюю прибыль.
- Ниже отображается график прибыли по месяцам.

## Карта заказов

- В разделе «Карта» отображаются все заказы с координатами. Маркеры имеют разные цвета в зависимости от статуса заказа.
- Кликните по маркеру, чтобы увидеть информацию о заказе.

## Выход из системы

- Для выхода просто закройте вкладку браузера. При следующем входе нужно будет снова ввести логин и пароль.
