# Установка и настройка CRM

## Требования

- Docker и Docker Compose (для базы данных, бэкенда и ML-сервиса)
- Node.js 18+ (для фронтенда, если запускаете локально)
- Python 3.12+ (если запускаете бэкенд локально, но рекомендуется через Docker)

## Быстрый старт с Docker (рекомендуется)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/AndreiZhura/CRM.git
   cd CRM
   ```
